# C Bank
Simple bank project implemented in C language, with basic banking functionalities | Projeto de um banco simples implementado em linguagem C, com funcionalidades bancárias básicas

## Functionalities (Funcionalidades)
- Account Creation (Criar uma Conta)
- Ballance Checking (Checar Saldo)
- Deposit Funds (Fazer um Depósito)
- Withdraw Funds (Fazer um Saque)
- Transfer Funds (Fazer uma Transferência)
- Delete an Account (Encerrar uma Conta)
